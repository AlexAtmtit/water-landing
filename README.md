# ТИШЬ — тишина, ставшая водой

Статический лендинг вымышленного бренда ледниковой воды. Все тексты на русском. Изображения и шрифты находятся в проекте; сторонних запросов, аналитики, cookies, серверной части и платных зависимостей нет.

## Посмотреть локально

Откройте `index.html` в браузере или запустите из папки проекта:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Установка npm и сборка не нужны.

## Бесплатная публикация на GitHub Pages

1. Создайте на GitHub **публичный** репозиторий, например `tish-water`.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `premium.css`, `script.js`, `.nojekyll` и всю папку `assets`. Можно загрузить также документацию. Не загружайте саму внешнюю папку проекта: `index.html` должен лежать в корне.
3. Сохраните файлы в ветку `main`.
4. Откройте **Settings → Pages → Build and deployment**.
5. В **Source** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**. Нажмите **Save**.
6. Дождитесь успешной публикации. Адрес появится в Pages: `https://<имя-пользователя>.github.io/tish-water/`.
7. Откройте ссылку и проверьте картинки, переходы и кнопку «Рассмотреть бутылку».

Все пути относительные: сайт работает как в корне домена, так и в подпапке репозитория. Собственный домен не требуется. Не добавляйте CNAME, если домен не настроен. Если при загрузке через браузер скрытый `.nojekyll` не попал в репозиторий, создайте его через **Add file → Create new file**; оставьте пустым или добавьте перевод строки.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Устройство

- `index.html` — шесть разделов, русские тексты и нативное диалоговое окно.
- `styles.css` — адаптивная композиция, ледяные слои, эффекты и режим уменьшенного движения.
- `premium.css` — утверждённые в MagicPath светлый первый экран и тёмный раздел деталей бутылки.
- `script.js` — появление разделов, небольшое движение льдинок и управление диалогом.
- `assets/images/` — девять сгенерированных изображений в WebP и уменьшенные версии фотографий.
- `assets/fonts/` — локальные Cormorant Garamond и Manrope (кириллица и латиница), CSS и лицензии SIL OFL.
- `ASSETS.md` — происхождение изображений и задания для генерации.

Русское название нанесено HTML-слоем, поэтому оно чёткое и не зависит от качества текста в генерации. При отключённом JavaScript история полностью видна, а ссылки просмотра открывают фотографию. Декоративные слои не мешают нажатиям. При `prefers-reduced-motion: reduce` движение отключается. Если браузер не поддерживает backdrop-filter, остаются изображения льда.

Это имиджевая дизайн-концепция: продукт, история и способ производства вымышлены. Не представлены как подтверждённые характеристики реального товара.

## Обновлённый дизайн

Светлый первый экран и тёмный раздел бутылки перенесены из утверждённого макета MagicPath. Бутылка использует локальный PNG с прозрачностью `assets/images/product-cutout.png`. Раздел деталей поддерживает вкладки «Стекло», «Крышка», «Свет», клавиши ←/→, Home/End и режим уменьшенного движения. React, сборка и внешние запросы не нужны. Остальные разделы истории сохранены.
